Make yourself comfortable.

Your language.

A shortcut back.

Read the privacy policy

Connect a service you choose.

Use your own model endpoint and API key. Requests go directly to that service, with no Aside relay. Model access is required for AI features; provider charges and terms apply.

Know where your words go.

Settings, API keys, collections, and request history are stored in your browser. Model features send the required content to your chosen service. With a model configured, Today’s thought can generate on your first Collection visit each day; hide it to stop automatic generation.

No Aside account, analytics, or cloud sync. The model provider’s own privacy policy applies to requests it receives.

Bring Aside to your next read.

Open source. Available to install from GitHub while the Chrome Web Store submission is under review.

  1. Install the extension.

    Follow the GitHub guide to build Aside and load it into Chrome. You’ll need Node.js 22 or later and Chrome 120 or later.

  2. Connect your model.

    Open Settings, add your service address and API key, test the connection, and select a model.

  3. Open a page and read.

    Select some text or open the floating menu to get started. Page tools work on regular websites where Chrome allows extensions.
