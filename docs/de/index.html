Klarer verstehen. Tiefer denken.

Übersetzen Sie Webseiten, lassen Sie schwierige Absätze erklären, erfassen Sie Kernaussagen und stellen Sie Fragen zum Text. Die Übersetzung bleibt beim Original, ohne ständigen Wechsel in ein separates Chatfenster.

Für Chrome 120+. Kostenlos, ohne Registrierung. Verbinden Sie beliebige kompatible Cloud- oder lokale Modelle (Modelldienste können Gebühren berechnen).

Datenschutzerklärung lesen (Englisch)

Gut zu wissen.

Ist Aside kostenlos?

Aside ist kostenlos und unter der MIT-Lizenz quelloffen. Für KI-Funktionen brauchen Sie eigenen Modellzugang. Anbieter können Anfragen berechnen; Modellabonnements und API-Guthaben sind nicht enthalten.

Welche Modelle kann ich verwenden?

Wählen Sie einen Dienst mit einer der vier oben genannten Schnittstellen. Geben Sie unter Modellverbindungen Adresse und API-Schlüssel ein, testen Sie die Verbindung und wählen Sie ein Modell. Sie können mehrere Verbindungen speichern und pro Aktion zuweisen.

Kann ich ein lokales Modell nutzen?

Ja, mit einem lokalen Dienst, der eine kompatible API anbietet, etwa Ollama. Wählen Sie OpenAI-compatible Chat Completions und geben Sie die localhost-Adresse an. Dienst und Modell müssen die verwendeten Anfragen unterstützen. Lokales HTTP ist auf localhost, 127.0.0.1 und [::1] begrenzt.

Wohin werden meine Leseinhalte gesendet?

KI-Funktionen senden die benötigten Inhalte direkt an Ihren Modelldienst. Nach dem Start einer Seitenübersetzung können beim Scrollen weitere Absätze gesendet werden. Ist ein Modell eingerichtet, entsteht der Tagesgedanke beim ersten täglichen Öffnen der Sammlung und kann gespeicherte Texte berücksichtigen. Beginnen Sie mit einer lesenswerten Seite.

Laden Sie die fertige Erweiterung herunter. Node.js und Build-Werkzeuge sind nicht nötig.

  1. Herunterladen.

    Laden Sie über den Button unten das Erweiterungs-ZIP herunter, nicht das automatisch erzeugte GitHub-Archiv „Source code“.

  2. Entpacken.

    Entpacken Sie das ZIP in einen dauerhaft aufbewahrten Ordner. Chrome lädt die Erweiterung von dort.

  3. In Chrome laden.

    Öffnen Sie chrome://extensions, aktivieren Sie den Entwicklermodus, wählen Sie Entpackte Erweiterung laden und anschließend den entpackten Ordner.
