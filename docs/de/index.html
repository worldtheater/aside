Deine Einstellungen, auf jedem Gerät.

Synchronisiere optional Modellverbindungen, Leseaktionen und Reflexionseinstellungen über dein Browserkonto. Deine Einstellungen werden vor dem Verlassen des Geräts mit deiner Passphrase verschlüsselt.

Eine Passphrase für alle Geräte.

Verwende auf allen Geräten denselben Browser und dasselbe Konto. Aktiviere die Browsersynchronisierung und tritt in Aside mit derselben Passphrase bei. Zwischen Chrome, Edge und Firefox werden keine Einstellungen synchronisiert. Erlaube den Modellzugriff auf jedem Gerät separat.

Bleibt auf dem jeweiligen Gerät.

Sammlungen, erzeugte Reflexionen, Anfrageverlauf und Cache werden nicht synchronisiert. Sprache und Darstellung lassen sich ebenfalls pro Gerät einstellen.

Gut zu wissen.

Ist Aside kostenlos?

Aside ist kostenlos und unter der MIT-Lizenz quelloffen. Für KI-Funktionen brauchen Sie eigenen Modellzugang. Anbieter können Anfragen berechnen; Modellabonnements und API-Guthaben sind nicht enthalten.

Welche Modelle kann ich verwenden?

Wählen Sie einen Dienst mit einer der vier oben genannten Schnittstellen. Geben Sie unter Modellverbindungen Adresse und API-Schlüssel ein, testen Sie die Verbindung und wählen Sie ein Modell. Sie können mehrere Verbindungen speichern und pro Aktion zuweisen.

Kann ich ein lokales Modell nutzen?

Ja, mit einem lokalen Dienst, der eine kompatible API anbietet, etwa Ollama. Wählen Sie OpenAI-compatible Chat Completions und geben Sie die localhost-Adresse an. Dienst und Modell müssen die verwendeten Anfragen unterstützen. HTTP-Dienstadressen werden ebenfalls unterstützt. Verwenden Sie möglichst HTTPS; HTTP verschlüsselt weder API-Schlüssel noch Anfrageinhalte.

Wohin werden meine Leseinhalte gesendet?

Microsoft-Übersetzung sendet den Text direkt an Microsoft. KI-Funktionen senden die benötigten Inhalte direkt an Ihren Modelldienst. Nach dem Start einer Seitenübersetzung können beim Scrollen weitere Absätze gesendet werden. Ist ein Modell eingerichtet, entsteht der Tagesgedanke beim ersten täglichen Öffnen der Sammlung und kann gespeicherte Texte berücksichtigen. Blenden Sie ihn aus, um die automatische Erstellung zu stoppen. Es gelten die Datenrichtlinien des Anbieters. Datenschutzerklärung lesen (Englisch)

Manuell installieren.

Wähle deinen Browser und folge den Schritten.

  1. Herunterladen und entpacken.

    Lade die ZIP-Datei der Erweiterung herunter und entpacke sie in einen dauerhaften Ordner. Wähle das Erweiterungspaket, nicht das GitHub-Archiv „Source code“.

  2. Erweiterungen öffnen.

    Gib chrome://extensions in die Adressleiste von Chrome ein.

  3. Erweiterung laden.

    Aktiviere Entwicklermodus, wähle Entpackte Erweiterung laden und dann den entpackten Ordner mit manifest.json.
