Votre choix de modèle.

Connectez votre service avec son adresse et sa clé API. Aside prend en charge ces interfaces :

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

Les services locaux compatibles accessibles sur localhost sont également pris en charge.

Une connexion directe.

Les requêtes sont envoyées directement au service de modèle choisi, sans serveur relais ni analyse d’usage par Aside. Vos collections et l’historique des requêtes restent dans votre navigateur.

Vos réglages, sur chaque appareil.

Synchronisez, si vous le souhaitez, vos connexions aux modèles, actions de lecture et paramètres de réflexion via votre compte de navigateur. Vos réglages sont chiffrés avec votre phrase secrète avant de quitter l’appareil.

La même phrase secrète partout.

Utilisez le même navigateur et le même compte sur chaque appareil, activez la synchronisation, puis rejoignez-la dans Aside avec la même phrase secrète. Les réglages ne se synchronisent pas entre Chrome, Edge et Firefox. Autorisez l’accès aux modèles sur chaque appareil.

Conservé sur chaque appareil.

Les collections, réflexions générées, historiques de requêtes et caches ne sont pas synchronisés. La langue et l’apparence restent également propres à chaque appareil.

Quelques réponses utiles.

Aside est-il gratuit ?

Aside est gratuit et open source sous licence MIT. Les fonctions IA nécessitent votre propre accès à un modèle. Le fournisseur peut facturer les requêtes ; aucun abonnement ni crédit API n’est inclus.

Quels modèles puis-je utiliser ?

Choisissez un service compatible avec l’une des quatre interfaces ci-dessus. Dans Connexions aux modèles, saisissez son adresse et la clé API, testez la connexion, puis choisissez le modèle. Vous pouvez conserver plusieurs connexions et les affecter à différentes actions.

Puis-je utiliser un modèle local ?

Oui, avec un service local proposant une API compatible, comme Ollama. Sélectionnez OpenAI-compatible Chat Completions et indiquez son adresse localhost. Le service et le modèle doivent accepter les requêtes utilisées. Les adresses de service HTTP sont aussi prises en charge. Privilégiez HTTPS ; HTTP ne chiffre ni les clés API ni le contenu des requêtes.

Où vont les données de ma lecture ?

La traduction Microsoft envoie le texte directement à Microsoft. Les fonctions IA envoient les contenus nécessaires directement au service de modèle choisi. Une fois la traduction de page lancée, le défilement peut envoyer d’autres passages. Avec un modèle configuré, la pensée du jour se génère à la première ouverture quotidienne de la collection et peut utiliser les passages enregistrés. Masquez-la pour arrêter cette génération automatique. La politique du fournisseur s’applique. Lire la politique de confidentialité (anglais)

Installer manuellement.

Choisissez votre navigateur et suivez les étapes.

  1. Télécharger et extraire.

    Téléchargez le ZIP de l’extension et extrayez-le dans un dossier à conserver. Choisissez le paquet de l’extension, pas l’archive « Source code » de GitHub.

  2. Ouvrir les extensions.

    Saisissez chrome://extensions dans la barre d’adresse de Chrome.

  3. Charger l’extension.

    Activez Mode développeur, choisissez Charger l’extension non empaquetée, puis le dossier extrait contenant manifest.json.

Télécharger le ZIP Chrome Guide d’installation complet

Conservez le dossier d’installation. Pour une mise à jour, remplacez son contenu et rechargez l’extension. Les installations manuelles ne se mettent pas à jour automatiquement.
