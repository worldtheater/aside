Votre choix de modèle.

Connectez votre service avec son adresse et sa clé API. Aside prend en charge ces interfaces :

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

Les services locaux compatibles accessibles sur localhost sont également pris en charge.

Une connexion directe.

Les requêtes sont envoyées directement au service de modèle choisi, sans serveur relais ni analyse d’usage par Aside. Vos collections et l’historique des requêtes restent dans votre navigateur.

Vos réglages, sur chaque appareil.

Synchronisez, si vous le souhaitez, vos connexions aux modèles, actions de lecture et paramètres de réflexion via Chrome. Vos réglages sont chiffrés avec la phrase secrète de votre choix avant de quitter l’appareil.

La même phrase secrète partout.

Connectez-vous au même compte Chrome avec la synchronisation activée, puis rejoignez la synchronisation dans Aside avec la même phrase secrète. Autorisez l’accès aux services de modèles sur chaque appareil.

Conservé sur chaque appareil.

Les collections, réflexions générées, historiques de requêtes et caches ne sont pas synchronisés. La langue et l’apparence restent également propres à chaque appareil.

Quelques réponses utiles.

Aside est-il gratuit ?

Aside est gratuit et open source sous licence MIT. Les fonctions IA nécessitent votre propre accès à un modèle. Le fournisseur peut facturer les requêtes ; aucun abonnement ni crédit API n’est inclus.

Quels modèles puis-je utiliser ?

Choisissez un service compatible avec l’une des quatre interfaces ci-dessus. Dans Connexions aux modèles, saisissez son adresse et la clé API, testez la connexion, puis choisissez le modèle. Vous pouvez conserver plusieurs connexions et les affecter à différentes actions.

Puis-je utiliser un modèle local ?

Oui, avec un service local proposant une API compatible, comme Ollama. Sélectionnez OpenAI-compatible Chat Completions et indiquez son adresse localhost. Le service et le modèle doivent accepter les requêtes utilisées. Les connexions HTTP locales sont limitées à localhost, 127.0.0.1 et [::1].

Où vont les données de ma lecture ?

Les fonctions IA envoient les contenus nécessaires directement au service de modèle choisi. Une fois la traduction de page lancée, le défilement peut envoyer d’autres passages. Avec un modèle configuré, la pensée du jour se génère à la première ouverture quotidienne de la collection et peut utiliser les passages enregistrés. Masquez-la pour arrêter cette génération automatique. La politique du fournisseur s’applique. Lire la politique de confidentialité (anglais)

Installer manuellement depuis GitHub

  1. Téléchargez.

    Utilisez le bouton ci-dessous pour obtenir le ZIP de l’extension, et non l’archive « Source code » générée par GitHub.

  2. Décompressez.

    Décompressez le ZIP dans un dossier que vous conserverez. Chrome chargera l’extension depuis ce dossier.

  3. Chargez dans Chrome.

    Ouvrez chrome://extensions, activez le Mode développeur, choisissez Charger l’extension non empaquetée, puis sélectionnez le dossier extrait.
