Você escolhe o modelo.

Conecte seu serviço usando o endereço e a chave API. O Aside oferece estas interfaces:

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

Também são aceitos serviços locais compatíveis acessíveis por localhost.

Uma conexão direta.

As solicitações vão diretamente ao serviço configurado. Não há servidor intermediário nem análise de uso. Configurações, chaves, coleção e histórico ficam no navegador.

Bom saber.

O Aside é gratuito?

O Aside é gratuito e de código aberto sob a licença MIT. As funções de IA exigem acesso próprio a um modelo. O provedor pode cobrar pelas solicitações; assinaturas ou créditos API não estão incluídos.

Quais modelos posso usar?

Escolha um serviço compatível com uma das quatro interfaces acima. Em Conexões de modelos, informe o endereço e a chave API, teste a conexão e selecione o modelo. É possível salvar várias conexões e escolher uma para cada ação.

Posso usar um modelo local?

Sim, com um serviço local que forneça uma API compatível, como o Ollama. Selecione OpenAI-compatible Chat Completions e informe o endereço localhost. O serviço e o modelo precisam aceitar as solicitações usadas. HTTP local é limitado a localhost, 127.0.0.1 ou [::1].

Para onde vão os dados da minha leitura?

As funções de IA enviam o conteúdo necessário diretamente ao serviço escolhido. Após iniciar a tradução da página, rolar pode enviar mais trechos. Com um modelo configurado, a reflexão do dia é gerada na primeira abertura diária da coleção e pode usar textos salvos. Oculte-a para interromper a geração automática. Vale a política de dados do provedor. Ler a política de privacidade (inglês)

Comece por uma página que merece atenção.

Baixe a extensão pronta para carregar. Não é necessário Node.js nem ferramentas de compilação.

  1. Baixe.

    Use o botão abaixo para baixar o ZIP da extensão, não o arquivo “Source code” gerado pelo GitHub.

  2. Extraia.

    Extraia o ZIP para uma pasta que será mantida. O Chrome carrega a extensão a partir dela.

  3. Carregue no Chrome.

    Abra chrome://extensions, ative o Modo do desenvolvedor, selecione Carregar sem compactação e escolha a pasta extraída.
