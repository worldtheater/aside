Privacy Policy

Last updated October 25, 2026

Data on your device

Aside uses browser extension storage and local databases to provide its features. The extension does not send these stores to the developer.

Settings and connections
Your preferences, custom instructions, per-site settings, model service addresses, model names, and API keys. Keys are used to authenticate requests to the service you configure.
Collections and reflections
Passages you save, original and processed text, page titles and URLs, action names, save dates, and your reflection settings and latest saved reflection.
Request history
Model and connection names, timestamps, status, token counts, instructions, submitted content, and received output. Failed or interrupted calls may retain partial output. Connection credentials and authorization headers are not added to this history.
Result cache
Previously generated results and cache identifiers, used to avoid repeating the same model request. Results can contain personal information from the source text.
Recent tabs
Tab and window identifiers and their activation order, held in browser session storage so the shortcut can switch between recently viewed tabs. This feature does not maintain a permanent URL history.

Model requests

When you translate, explain, summarize, preview an action, or submit a question, Aside sends the required text and instructions directly to the service URL saved in Model connections. Depending on the feature, this may include selected text, extracted page content, your question, a quoted passage, and context such as page titles, section titles, or table headings. That content may contain personal or sensitive information.

After you start inline page processing, additional visible or nearby passages may be sent as you scroll or the page changes. Quick Q&A prepares a quote from your selection or the page, but does not send the question until you submit it.

Today's thought can run automatically: with a model configured and the reflection area visible, the first visit to Collection each local day can generate a reflection. Preview and refresh also send requests. If Use my collection is enabled, a request includes titles and excerpts from up to five saved passages, together with your instructions and the date.

The recipient is the operator of the model endpoint you choose: for example, OpenAI, Anthropic, Google, xAI, another compatible provider, or a local server you control. The service receives the request content, authentication information, and normal network metadata such as your IP address. Its own terms and privacy policy determine retention, processing location, and any use for model training. Aside does not control those practices.

Testing a connection sends an authenticated request to retrieve its model list; it does not submit page text for generation. Requests do not pass through an Aside server.

Other connections

Website appearance. Dark mode uses the bundled Dark Reader engine locally. It may retrieve stylesheets or images referenced by the page from their original hosts, which receive normal network metadata. Dark mode does not send page content to a model. Site icons are requested through Chrome's favicon interface.

This page and support. This static page is hosted by GitHub Pages. It contains no analytics, advertising, third-party fonts, or scripts. GitHub may process technical visit data, including IP addresses, under the GitHub Privacy Statement. If you open a project link or submit an issue, GitHub handles that interaction, and information you post in a public issue is visible to the maintainers and others.

Your controls and retention

Settings, collections, and request history have no scheduled expiry. They remain in your browser until you remove them, clear extension data, or uninstall Aside. The result cache has a size limit and evicts older results as needed. Session tab records are cleared when the browser restarts or the extension is reloaded. A new saved reflection replaces the previous card; its request may still remain in history.

  • Delete saved passages from Collection.
  • Clear request history from Usage to remove both summaries and input/output details. Clear the result cache separately on the same page.
  • Delete a connection from Model connections to remove its saved API key. Revoke the key with its provider if you want to invalidate it.
  • Disable Use my collection to stop including saved passages in future reflections. Hide Today's thought to stop its automatic generation; hiding it does not erase the saved text or history.
  • Stop page processing, restrict site access in Chrome, or disable the extension to stop the corresponding page features. Uninstalling removes the extension's local data.

These stores are independent: deleting a passage or connection does not remove copies already recorded in history or generated results in the cache. Local deletion does not delete requests retained by a model provider. Contact that provider to exercise controls over its copies. The Aside maintainers cannot access or erase data stored only in your browser.

Security

Remote model endpoints must use HTTPS. HTTP is allowed only for loopback addresses on your own device. API keys are kept in restricted extension storage and are not provided to web page content scripts. Local storage is not an encrypted password vault; protect access to your device and browser profile.

Aside uses page access for reading tools and appearance changes, extension storage for local settings and data, and service-specific permissions for model requests. It does not use these permissions to build advertising profiles.

Limited use

Aside uses user data only for the features described in this policy, consistent with the Chrome Web Store User Data Policy and Limited Use requirements. The developer does not sell user data, use it for advertising or credit decisions, or collect reading content to train models. Aside has no telemetry or behavioral analytics. Your chosen model service's separate practices are described above.

Changes and contact

We will update this page and its date when data practices change. Material changes will also be disclosed through the extension or its release information as appropriate.

For questions about this policy, contact the maintainers through the Aside issue tracker. Issues are public: do not post API keys, private page content, or other sensitive information.
