旁白免費嗎？

旁白免費開源，採用 MIT 授權。AI 功能需自備模型服務；服務商可能收取費用，旁白不提供模型訂閱或 API 額度。

可以使用哪些模型？

選擇支援上述四種介面之一的服務。在「模型連線」中填入服務網址和 API Key，測試後選擇模型。可儲存多個連線，並為不同處理方式指定模型。

可以使用本機模型嗎？

可以，只要本機服務提供相容 API，例如 Ollama。選擇 OpenAI-compatible Chat Completions，填入 localhost 位址。服務與模型須支援所用請求。也支援 HTTP 服務位址。建議優先使用 HTTPS；HTTP 不加密 API Key 和請求內容。

我的閱讀資料會傳到哪裡？

微軟翻譯會將文字直接傳送至微軟。AI 功能會將所需內容直接傳送給選定的模型服務。啟動整頁翻譯後，捲動可能傳送更多段落。設定模型後，每天首次開啟收藏頁會生成今日隨想，並可選擇參考收藏；隱藏隨想即可停止自動生成。資料處理遵循服務商的政策。閱讀隱私權政策（英文）

手動安裝。

選擇瀏覽器，依步驟載入本機擴充套件。

  1. 下載並解壓縮。

    下載擴充套件 ZIP，解壓縮到固定資料夾。請選擇擴充套件安裝包，而非 GitHub 的「Source code」原始碼封存檔。

  2. 開啟擴充套件管理頁。

    在 Chrome 網址列輸入 chrome://extensions。

  3. 載入擴充套件。

    開啟開發人員模式，點選載入未封裝項目，選擇解壓縮後含有 manifest.json 的資料夾。
