สองภาษาในหน้าเดียว

อ่านคำแปลโดยยังเห็นบริบทของต้นฉบับ

อ่านพร้อมบริบท

คำแปลแสดงใต้ย่อหน้าต้นฉบับ ทำให้เห็นทั้งสองภาษาและเทียบกันได้

เลื่อนต่อ แปลต่อ

แปลส่วนที่มองเห็นก่อน แล้วประมวลผลย่อหน้าถัดไปเมื่อเลื่อนหรือเนื้อหาหน้าเว็บเปลี่ยน

กลับสู่ต้นฉบับได้เสมอ

คืนหน้าเว็บเป็นต้นฉบับได้ทุกเมื่อ โดยยังตามตำแหน่งที่อ่านอยู่ได้

ถามได้โดยไม่ต้องออกจากหน้า

เลือกข้อความเพื่อแปล อ่านคำอธิบาย หรือถามเกี่ยวกับข้อความนั้นในแผงลอย

เปิดถามตอบด่วนจากเมนูลอยหรือแป้นพิมพ์ลัดเพื่อถามคำถามได้โดยตรง ใช้การแปลข้อความเพื่อแปลข้อความที่พิมพ์หรือวางได้ตามต้องการ

Alt + Q ถามตอบด่วน · Alt + T แปลข้อความ

เก็บข้อความพร้อมบริบท

บันทึกผลลัพธ์ที่มีประโยชน์พร้อมต้นฉบับและแหล่งที่มา ค้นหาในคอลเลกชัน กลับมาอ่าน และต่อยอดความคิดได้

ข้อคิดวันนี้เสนอความคิดสั้น ๆ ในแต่ละวัน และเลือกให้อ้างอิงจากคอลเลกชันได้

ปิดไฟแล้ว ก็ไปต่อได้

เอนจิน Dark Reader ในตัวปรับหน้าเว็บเป็นโหมดมืดสำหรับการอ่านในที่แสงน้อย เปิดใช้แยกแต่ละเว็บไซต์หรือตามการตั้งค่าระบบได้

ปรับสี ขนาดตัวอักษร และระยะบรรทัดของผลลัพธ์ให้เหมาะกับการอ่านของคุณ

เครื่องมือที่เข้ากับวิธีอ่านของคุณ

สร้างการทำงานของคุณเอง

อธิบายแนวคิด ตีความงานเขียนโบราณ หรือดึงประเด็นสำคัญ เพิ่มข้อกำหนดให้การทำงานที่มีอยู่ หรือสร้างและทดลองการทำงานของคุณเอง

เลือกภาษาของคุณ

มีภาษาอินเทอร์เฟซให้เลือก 15 ภาษา และตั้งค่าภาษาผลลัพธ์แยกตามการทำงานได้

กลับไปดูแหล่งอ้างอิงได้เร็ว

ใช้ Alt + W สลับระหว่างสองแท็บที่ใช้ล่าสุดในหน้าต่าง บน macOS ใช้ Option และเปลี่ยนทางลัดได้ใน Chrome / Edge

เลือกโมเดลได้เอง

เชื่อมต่อบริการโมเดลด้วยที่อยู่บริการและคีย์ API โดย Aside รองรับอินเทอร์เฟซต่อไปนี้

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

รองรับบริการโมเดลในเครื่องที่มี API เข้ากันได้และเข้าถึงผ่าน localhost

เชื่อมต่อโดยตรง

คำขอจะส่งตรงไปยังบริการโมเดลที่คุณเลือก โดยไม่มีเซิร์ฟเวอร์ตัวกลางหรือการเก็บข้อมูลวิเคราะห์การใช้งานจาก Aside คอลเลกชันและประวัติคำขอจะเก็บไว้ในเบราว์เซอร์ของคุณ

อ่านนโยบายความเป็นส่วนตัว (อังกฤษ)

การตั้งค่าที่คุ้นเคย ในทุกอุปกรณ์

เลือกซิงค์การเชื่อมต่อโมเดล วิธีประมวลผลข้อความ และการตั้งค่าข้อคิดผ่านบัญชีเบราว์เซอร์ได้ การตั้งค่าจะถูกเข้ารหัสด้วยวลีรหัสผ่านของคุณก่อนส่งออกจากอุปกรณ์

ใช้วลีรหัสผ่านเดียวกันทุกอุปกรณ์

ใช้เบราว์เซอร์และบัญชีเดียวกันในทุกอุปกรณ์ เปิดการซิงค์ของเบราว์เซอร์ แล้วเข้าร่วมใน Aside ด้วยวลีรหัสผ่านเดียวกัน การตั้งค่าจะไม่ซิงค์ข้าม Chrome, Edge และ Firefox ต้องอนุญาตการเข้าถึงโมเดลแยกในแต่ละอุปกรณ์

เก็บไว้ในแต่ละอุปกรณ์

คอลเลกชัน ข้อคิดที่สร้างแล้ว ประวัติคำขอ และแคชจะไม่ซิงค์ ภาษาและรูปแบบการแสดงผลก็ตั้งค่าแยกกันในแต่ละอุปกรณ์

สิ่งที่น่ารู้

Aside ใช้ฟรีหรือไม่

Aside ฟรีและเป็นโอเพนซอร์สภายใต้สัญญาอนุญาต MIT ฟีเจอร์ AI ต้องใช้สิทธิ์เข้าถึงโมเดลของคุณเอง ผู้ให้บริการอาจคิดค่าคำขอ โดยไม่รวมการสมัครโมเดลหรือเครดิต API

ใช้โมเดลอะไรได้บ้าง

เลือกบริการที่รองรับหนึ่งในสี่อินเทอร์เฟซข้างต้น ในการเชื่อมต่อโมเดล ให้กรอกที่อยู่และคีย์ API ทดสอบการเชื่อมต่อแล้วเลือกโมเดล บันทึกได้หลายการเชื่อมต่อและกำหนดให้แต่ละการทำงานได้

ใช้โมเดลในเครื่องได้ไหม

ได้ หากบริการในเครื่องมี API ที่เข้ากันได้ เช่น Ollama เลือก OpenAI-compatible Chat Completions แล้วกรอกที่อยู่ localhost บริการและโมเดลต้องรองรับคำขอที่ใช้ รองรับที่อยู่บริการ HTTP ด้วย ควรใช้ HTTPS หากทำได้ เพราะ HTTP ไม่เข้ารหัสคีย์ API หรือเนื้อหาคำขอ

ข้อมูลที่อ่านส่งไปที่ไหน

การแปลด้วย Microsoft ส่งข้อความตรงไปยัง Microsoft ฟีเจอร์ AI ส่งเนื้อหาที่จำเป็นตรงไปยังบริการโมเดลที่เลือก เมื่อเริ่มแปลหน้าเว็บแล้ว การเลื่อนอาจส่งข้อความเพิ่มเติม หลังตั้งค่าโมเดล ข้อคิดวันนี้จะสร้างเมื่อเปิดคอลเลกชันครั้งแรกของวัน และเลือกให้อ้างอิงข้อความที่บันทึกได้ ซ่อนส่วนนี้เพื่อหยุดการสร้างอัตโนมัติ การใช้ข้อมูลเป็นไปตามนโยบายผู้ให้บริการ อ่านนโยบายความเป็นส่วนตัว (อังกฤษ)

ติดตั้งด้วยตนเอง

เลือกเบราว์เซอร์และทำตามขั้นตอนเพื่อติดตั้งส่วนขยาย

  1. ดาวน์โหลดและแตกไฟล์

    ดาวน์โหลด ZIP ของส่วนขยายแล้วแตกไฟล์ไปยังโฟลเดอร์ที่จะเก็บไว้ เลือกแพ็กเกจส่วนขยาย ไม่ใช่ไฟล์ “Source code” ของ GitHub

  2. เปิดหน้าส่วนขยาย

    ป้อน chrome://extensions ในแถบที่อยู่ของ Chrome

  3. โหลดส่วนขยาย

    เปิด โหมดนักพัฒนาซอฟต์แวร์ เลือก โหลดส่วนขยายที่คลายการแพคแล้ว แล้วเลือกโฟลเดอร์ที่แตกไฟล์และมี manifest.json

ดาวน์โหลด ZIP สำหรับ Chrome คู่มือการติดตั้งฉบับเต็ม
