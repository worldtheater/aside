ผู้ช่วยอ่านด้วย AI · ส่วนขยาย Chrome แบบโอเพนซอร์ส

เข้าใจข้อความชัดขึ้น คิดได้ลึกกว่าเดิม

ใช้ AI แปลหน้าเว็บ อธิบายข้อความที่เข้าใจยาก สรุปประเด็นสำคัญ และถามเกี่ยวกับสิ่งที่กำลังอ่าน คำแปลอยู่ข้างต้นฉบับ จึงไม่ต้องสลับไปมาระหว่างหน้าเว็บกับหน้าต่างแชต

เพิ่มใน Chromeวิธีติดตั้ง

สำหรับ Chrome 120 ขึ้นไป ใช้งานฟรีโดยไม่ต้องสมัคร เชื่อมต่อโมเดลบนคลาวด์หรือในเครื่องได้ตามต้องการ (บริการโมเดลอาจมีค่าใช้จ่าย)

สัญญาอนุญาต MITเวอร์ชัน 0.1.2

สองภาษาในหน้าเดียว

อ่านคำแปลโดยยังเห็นบริบทของต้นฉบับ

อ่านพร้อมบริบท

คำแปลแสดงใต้ย่อหน้าต้นฉบับ ทำให้เห็นทั้งสองภาษาและเทียบกันได้

เลื่อนต่อ แปลต่อ

แปลส่วนที่มองเห็นก่อน แล้วประมวลผลย่อหน้าถัดไปเมื่อเลื่อนหรือเนื้อหาหน้าเว็บเปลี่ยน

กลับสู่ต้นฉบับได้เสมอ

คืนหน้าเว็บเป็นต้นฉบับได้ทุกเมื่อ โดยยังตามตำแหน่งที่อ่านอยู่ได้

ถามได้โดยไม่ต้องออกจากหน้า

เลือกข้อความเพื่อแปลหรืออธิบายในแผงลอย ใช้ถามตอบด่วนถามต่อโดยอ้างอิงข้อความที่เลือกหรือทั้งหน้าเว็บ

ล้างข้อความอ้างอิงเพื่อถามคำถามแยกต่างหากได้

Alt + Q เปิดถามตอบด่วน

เก็บข้อความพร้อมบริบท

บันทึกผลลัพธ์ที่มีประโยชน์พร้อมต้นฉบับและแหล่งที่มา ค้นหาในคอลเลกชัน กลับมาอ่าน และต่อยอดความคิดได้

ข้อคิดวันนี้เสนอความคิดสั้น ๆ ในแต่ละวัน และเลือกให้อ้างอิงจากคอลเลกชันได้

ปิดไฟแล้ว ก็ไปต่อได้

เอนจิน Dark Reader ในตัวปรับหน้าเว็บเป็นโหมดมืดสำหรับการอ่านในที่แสงน้อย เปิดใช้แยกแต่ละเว็บไซต์หรือตามการตั้งค่าระบบได้

ปรับสี ขนาดตัวอักษร และระยะบรรทัดของผลลัพธ์ให้เหมาะกับการอ่านของคุณ

เครื่องมือที่เข้ากับวิธีอ่านของคุณ

สร้างการทำงานของคุณเอง

อธิบายแนวคิด ตีความงานเขียนโบราณ หรือดึงประเด็นสำคัญ เพิ่มข้อกำหนดให้การทำงานที่มีอยู่ หรือสร้างและทดลองการทำงานของคุณเอง

เลือกภาษาของคุณ

มีภาษาอินเทอร์เฟซให้เลือก 15 ภาษา และตั้งค่าภาษาผลลัพธ์แยกตามการทำงานได้

กลับไปดูแหล่งอ้างอิงได้เร็ว

ใช้ Alt + W สลับระหว่างสองแท็บที่ใช้ล่าสุดในหน้าต่าง บน macOS ใช้ Option และเปลี่ยนทางลัดได้ใน Chrome

เลือกโมเดลได้เอง

เชื่อมต่อบริการโมเดลด้วยที่อยู่บริการและคีย์ API โดย Aside รองรับอินเทอร์เฟซต่อไปนี้

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

รองรับบริการโมเดลในเครื่องที่มี API เข้ากันได้และเข้าถึงผ่าน localhost

เชื่อมต่อโดยตรง

คำขอจะส่งตรงไปยังบริการโมเดลที่คุณเลือก โดยไม่มีเซิร์ฟเวอร์ตัวกลางหรือการเก็บข้อมูลวิเคราะห์การใช้งานจาก Aside คอลเลกชันและประวัติคำขอจะเก็บไว้ในเบราว์เซอร์ของคุณ

อ่านนโยบายความเป็นส่วนตัว (อังกฤษ)

การตั้งค่าที่คุ้นเคย ในทุกอุปกรณ์

เลือกซิงค์การเชื่อมต่อโมเดล วิธีประมวลผลข้อความ และการตั้งค่าข้อคิดผ่าน Chrome ได้ การตั้งค่าจะถูกเข้ารหัสด้วยวลีรหัสผ่านที่คุณตั้งก่อนส่งออกจากอุปกรณ์

ใช้วลีรหัสผ่านเดียวกันทุกอุปกรณ์

ลงชื่อเข้าใช้บัญชี Chrome เดียวกันและเปิดการซิงค์ จากนั้นเข้าร่วมใน Aside ด้วยวลีรหัสผ่านเดียวกัน ต้องอนุญาตให้เข้าถึงบริการโมเดลในแต่ละอุปกรณ์แยกกัน

เก็บไว้ในแต่ละอุปกรณ์

คอลเลกชัน ข้อคิดที่สร้างแล้ว ประวัติคำขอ และแคชจะไม่ซิงค์ ภาษาและรูปแบบการแสดงผลก็ตั้งค่าแยกกันในแต่ละอุปกรณ์

สิ่งที่น่ารู้

Aside ใช้ฟรีหรือไม่

Aside ฟรีและเป็นโอเพนซอร์สภายใต้สัญญาอนุญาต MIT ฟีเจอร์ AI ต้องใช้สิทธิ์เข้าถึงโมเดลของคุณเอง ผู้ให้บริการอาจคิดค่าคำขอ โดยไม่รวมการสมัครโมเดลหรือเครดิต API

ใช้โมเดลอะไรได้บ้าง

เลือกบริการที่รองรับหนึ่งในสี่อินเทอร์เฟซข้างต้น ในการเชื่อมต่อโมเดล ให้กรอกที่อยู่และคีย์ API ทดสอบการเชื่อมต่อแล้วเลือกโมเดล บันทึกได้หลายการเชื่อมต่อและกำหนดให้แต่ละการทำงานได้

ใช้โมเดลในเครื่องได้ไหม

ได้ หากบริการในเครื่องมี API ที่เข้ากันได้ เช่น Ollama เลือก OpenAI-compatible Chat Completions แล้วกรอกที่อยู่ localhost บริการและโมเดลต้องรองรับคำขอที่ใช้ การเชื่อมต่อ HTTP ในเครื่องจำกัดที่ localhost, 127.0.0.1 หรือ [::1]

ข้อมูลที่อ่านส่งไปที่ไหน

ฟีเจอร์ AI ส่งเนื้อหาที่จำเป็นตรงไปยังบริการโมเดลที่เลือก เมื่อเริ่มแปลหน้าเว็บแล้ว การเลื่อนอาจส่งข้อความเพิ่มเติม หลังตั้งค่าโมเดล ข้อคิดวันนี้จะสร้างเมื่อเปิดคอลเลกชันครั้งแรกของวัน และเลือกให้อ้างอิงข้อความที่บันทึกได้ ซ่อนส่วนนี้เพื่อหยุดการสร้างอัตโนมัติ การใช้ข้อมูลเป็นไปตามนโยบายผู้ให้บริการ อ่านนโยบายความเป็นส่วนตัว (อังกฤษ)

เริ่มจากหน้าที่อยากอ่านอย่างตั้งใจ

ติดตั้ง Aside จาก Chrome Web Store แล้วเชื่อมต่อบริการโมเดลที่คุณเลือกเพื่อเริ่มใช้งาน

เพิ่มใน Chrome

จากนั้นเปิดการตั้งค่า Aside และเพิ่มการเชื่อมต่อโมเดล กลับไปยังหน้าเว็บทั่วไปเพื่อเริ่มแปลหรือถามคำถาม

ติดตั้งด้วยตนเองจาก GitHub

  1. ดาวน์โหลด

    ใช้ปุ่มด้านล่างดาวน์โหลด ZIP ของส่วนขยาย ไม่ใช่ไฟล์ “Source code” ที่ GitHub สร้างให้อัตโนมัติ

  2. แตกไฟล์

    แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่จะเก็บไว้ Chrome จะโหลดส่วนขยายจากโฟลเดอร์นั้น

  3. โหลดใน Chrome

    เปิด chrome://extensions เปิดใช้ โหมดนักพัฒนาซอฟต์แวร์ เลือก โหลดส่วนขยายที่คลายการแพคแล้ว แล้วเลือกโฟลเดอร์ที่แตกไฟล์ไว้
