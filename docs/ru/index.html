Полезно знать.

Aside бесплатен?

Aside бесплатен и открыт по лицензии MIT. Для ИИ-функций нужен собственный доступ к модели. Провайдер может брать плату за запросы; подписка на модель и кредиты API не включены.

Какие модели можно использовать?

Выберите сервис с одним из четырёх указанных интерфейсов. В разделе подключения моделей введите адрес и ключ API, проверьте соединение и выберите модель. Можно сохранить несколько подключений и назначить их разным действиям.

Можно ли подключить локальную модель?

Да, если локальный сервис предоставляет совместимый API, например Ollama. Выберите OpenAI-compatible Chat Completions и укажите адрес localhost. Сервис и модель должны поддерживать используемые запросы. Также поддерживаются HTTP-адреса сервисов. По возможности используйте HTTPS: HTTP не шифрует API-ключи и содержимое запросов.

Куда отправляется содержимое страниц?

Перевод Microsoft отправляет текст напрямую в Microsoft. ИИ-функции отправляют необходимые материалы прямо выбранному провайдеру. После запуска перевода страницы при прокрутке могут отправляться новые фрагменты. Если модель настроена, мысль дня создаётся при первом открытии коллекции за день и может учитывать сохранённые тексты. Скройте этот блок, чтобы отключить автогенерацию. Действует политика обработки данных провайдера. Прочитать политику конфиденциальности (английский)

Установка вручную.

Выберите браузер и следуйте инструкции.

  1. Скачайте и распакуйте.

    Скачайте ZIP расширения и распакуйте его в постоянную папку. Выберите пакет расширения, а не архив «Source code» на GitHub.

  2. Откройте расширения.

    Введите chrome://extensions в адресную строку Chrome.

  3. Загрузите расширение.

    Включите Режим разработчика, выберите Загрузить распакованное расширение и укажите распакованную папку с manifest.json.
