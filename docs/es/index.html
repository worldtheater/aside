El modelo lo eliges tú.

Conecta un servicio mediante su dirección y clave API. Aside admite estas interfaces:

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

También admite servicios locales compatibles en localhost.

Una conexión directa.

Las solicitudes se envían directamente al servicio de modelos que elijas, sin servidor intermediario ni analítica de uso de Aside. Las colecciones y el historial de solicitudes se guardan en tu navegador.

Tu configuración, en cada dispositivo.

Sincroniza de forma opcional las conexiones a modelos, las acciones de lectura y los ajustes de reflexión a través de Chrome. La configuración se cifra con una frase de contraseña que eliges antes de salir del dispositivo.

La misma frase en todos tus dispositivos.

Inicia sesión en la misma cuenta de Chrome y activa la sincronización. Después, únete en Aside con la misma frase de contraseña. Autoriza el acceso a los servicios de modelos en cada dispositivo.

Se conserva en cada dispositivo.

Las colecciones, reflexiones generadas, historial de solicitudes y caché no se sincronizan. El idioma y la apariencia también se configuran por separado en cada dispositivo.

Algunas respuestas útiles.

¿Aside es gratis?

Aside es gratuito y de código abierto, con licencia MIT. Las funciones de IA requieren acceso propio a un modelo. El proveedor puede cobrar por las solicitudes; no se incluyen suscripciones ni créditos API.

¿Qué modelos puedo usar?

Elige un servicio compatible con una de las cuatro interfaces anteriores. En Conexiones de modelos, introduce la dirección y la clave API, prueba la conexión y elige un modelo. Puedes guardar varias conexiones y asignarlas a distintas acciones.

¿Puedo usar un modelo local?

Sí, con un servicio local que ofrezca una API compatible, como Ollama. Elige OpenAI-compatible Chat Completions e introduce la dirección localhost. El servicio y el modelo deben admitir las solicitudes utilizadas. El HTTP local se limita a localhost, 127.0.0.1 o [::1].

¿Adónde van los datos de mi lectura?

Las funciones de IA envían el contenido necesario directamente al servicio elegido. Tras iniciar la traducción de una página, al desplazarte se pueden enviar más pasajes. Con un modelo configurado, la reflexión del día se genera la primera vez que abres la colección cada día y puede usar textos guardados. Ocúltala para detener la generación automática. Se aplica la política de datos del proveedor. Leer la política de privacidad (inglés)

Instalar manualmente desde GitHub

  1. Descarga.

    Usa el botón de abajo para descargar el ZIP de la extensión, no el archivo «Source code» generado por GitHub.

  2. Extrae.

    Extrae el ZIP en una carpeta que vayas a conservar. Chrome cargará la extensión desde allí.

  3. Carga en Chrome.

    Abre chrome://extensions, activa el Modo desarrollador, elige Cargar descomprimida y selecciona la carpeta extraída.
