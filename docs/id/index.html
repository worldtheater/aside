Koneksi langsung.

Permintaan dikirim langsung ke layanan model pilihan Anda, tanpa server perantara atau analitik penggunaan dari Aside. Koleksi dan riwayat permintaan disimpan di browser Anda.

Pengaturan Anda, di setiap perangkat.

Anda dapat memilih untuk menyinkronkan koneksi model, tindakan membaca, dan pengaturan refleksi melalui akun browser. Pengaturan dienkripsi dengan frasa sandi Anda sebelum meninggalkan perangkat.

Satu frasa sandi di semua perangkat.

Gunakan browser dan akun yang sama di setiap perangkat, aktifkan sinkronisasi browser, lalu bergabung di Aside dengan frasa sandi yang sama. Pengaturan tidak disinkronkan antara Chrome, Edge, dan Firefox. Izinkan akses model di setiap perangkat.

Tetap di setiap perangkat.

Koleksi, refleksi yang dihasilkan, riwayat permintaan, dan cache tidak disinkronkan. Bahasa dan tampilan juga diatur secara terpisah pada setiap perangkat.

Hal yang perlu diketahui.

Apakah Aside gratis?

Aside gratis dan bersumber terbuka dengan lisensi MIT. Fitur AI memerlukan akses model Anda sendiri. Penyedia dapat mengenakan biaya permintaan; langganan model atau kredit API tidak disertakan.

Model apa yang bisa digunakan?

Pilih layanan yang mendukung salah satu dari empat antarmuka di atas. Di Koneksi model, isi alamat dan kunci API, uji koneksi, lalu pilih model. Anda dapat menyimpan beberapa koneksi dan menetapkannya per tindakan.

Bisakah memakai model lokal?

Ya, jika layanan lokal menyediakan API yang kompatibel, seperti Ollama. Pilih OpenAI-compatible Chat Completions dan gunakan alamat localhost. Layanan dan model harus mendukung permintaan yang digunakan. Alamat layanan HTTP juga didukung. Sebaiknya gunakan HTTPS; HTTP tidak mengenkripsi kunci API atau isi permintaan.

Ke mana data bacaan saya dikirim?

Terjemahan Microsoft mengirim teks langsung ke Microsoft. Fitur AI mengirim isi yang dibutuhkan langsung ke layanan pilihan Anda. Setelah terjemahan halaman dimulai, menggulir dapat mengirim bagian tambahan. Jika model telah diatur, renungan dibuat saat koleksi pertama kali dibuka setiap hari dan dapat merujuk teks tersimpan. Sembunyikan renungan untuk menghentikan pembuatan otomatis. Kebijakan data penyedia berlaku. Baca kebijakan privasi (Inggris)

Instal secara manual.

Pilih browser dan ikuti langkah-langkahnya.

  1. Unduh dan ekstrak.

    Unduh ZIP ekstensi dan ekstrak ke folder permanen. Pilih paket ekstensi, bukan arsip “Source code” dari GitHub.

  2. Buka pengelola ekstensi.

    Masukkan chrome://extensions di bilah alamat Chrome.

  3. Muat ekstensi.

    Aktifkan Mode developer, pilih Muat yang belum dipaketkan, lalu pilih folder hasil ekstraksi yang berisi manifest.json.
