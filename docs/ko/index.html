Aside는 무료인가요?

Aside는 MIT 라이선스의 무료 오픈 소스 소프트웨어입니다. AI 기능에는 본인의 모델 서비스가 필요합니다. 제공 업체가 요금을 청구할 수 있으며 모델 구독이나 API 크레딧은 포함되지 않습니다.

어떤 모델을 사용할 수 있나요?

위 네 가지 인터페이스 중 하나를 지원하는 서비스를 선택하세요. 모델 연결에서 주소와 API 키를 입력하고 연결을 테스트한 뒤 모델을 선택합니다. 여러 연결을 저장하고 처리 방식마다 지정할 수 있습니다.

로컬 모델도 사용할 수 있나요?

네. Ollama처럼 호환 API를 제공하는 로컬 서비스를 사용할 수 있습니다. OpenAI-compatible Chat Completions를 선택하고 localhost 주소를 입력하세요. 서비스와 모델이 사용할 요청을 지원해야 합니다. 로컬 HTTP 주소는 localhost, 127.0.0.1 또는 [::1]로 제한됩니다.

읽는 내용은 어디로 전송되나요?

번역 등 AI 기능은 필요한 내용을 선택한 모델 서비스로 직접 보냅니다. 페이지 번역을 시작하면 스크롤할 때 추가 문단이 전송될 수 있습니다. 모델 설정 후 매일 처음 컬렉션을 열 때 오늘의 생각을 생성하며, 원하면 저장한 내용을 참고합니다. 이 영역을 숨기면 자동 생성이 중단됩니다. 제공 업체의 데이터 정책이 적용됩니다. 개인정보 처리방침 읽기 (영어)

    chrome://extensions를 열고 개발자 모드를 켠 뒤 압축해제된 확장 프로그램을 로드합니다를 선택하고 압축을 푼 폴더를 지정하세요.
