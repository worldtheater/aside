요청은 선택한 모델 서비스로 직접 전송됩니다. Aside는 중계 서버나 사용 분석을 운영하지 않습니다. 컬렉션과 요청 기록은 브라우저에 저장됩니다.

다른 기기에서도 익숙한 설정으로.

모델 연결, 처리 방식, 단상 생성 설정을 브라우저 계정으로 선택적으로 동기화할 수 있습니다. 설정은 기기를 떠나기 전에 직접 정한 암호로 암호화됩니다.

모든 기기에서 같은 암호.

각 기기에서 같은 브라우저와 계정을 사용하고 브라우저 동기화를 켠 뒤, Aside에서 같은 암호로 참여하세요. Chrome, Edge, Firefox 사이에는 동기화되지 않습니다. 모델 서비스 접근 권한은 각 기기에서 따로 허용해야 합니다.

각 기기에 보관되는 내용.

컬렉션, 생성된 단상, 요청 기록과 캐시는 동기화하지 않습니다. 언어와 표시 스타일도 기기별로 설정합니다.

Aside는 무료인가요?

Aside는 MIT 라이선스의 무료 오픈 소스 소프트웨어입니다. AI 기능에는 본인의 모델 서비스가 필요합니다. 제공 업체가 요금을 청구할 수 있으며 모델 구독이나 API 크레딧은 포함되지 않습니다.

어떤 모델을 사용할 수 있나요?

위 네 가지 인터페이스 중 하나를 지원하는 서비스를 선택하세요. 모델 연결에서 주소와 API 키를 입력하고 연결을 테스트한 뒤 모델을 선택합니다. 여러 연결을 저장하고 처리 방식마다 지정할 수 있습니다.

로컬 모델도 사용할 수 있나요?

네. Ollama처럼 호환 API를 제공하는 로컬 서비스를 사용할 수 있습니다. OpenAI-compatible Chat Completions를 선택하고 localhost 주소를 입력하세요. 서비스와 모델이 사용할 요청을 지원해야 합니다. HTTP 서비스 주소도 지원합니다. 가능하면 HTTPS를 사용하세요. HTTP는 API 키와 요청 내용을 암호화하지 않습니다.

읽는 내용은 어디로 전송되나요?

Microsoft 번역은 텍스트를 Microsoft로 직접 보냅니다. AI 기능은 필요한 내용을 선택한 모델 서비스로 직접 보냅니다. 페이지 번역을 시작하면 스크롤할 때 추가 문단이 전송될 수 있습니다. 모델 설정 후 매일 처음 컬렉션을 열 때 오늘의 생각을 생성하며, 원하면 저장한 내용을 참고합니다. 이 영역을 숨기면 자동 생성이 중단됩니다. 제공 업체의 데이터 정책이 적용됩니다. 개인정보 처리방침 읽기 (영어)

브라우저를 선택하고 단계에 따라 확장 프로그램을 불러오세요.

  1. 다운로드 및 압축 해제.

    확장 프로그램 ZIP을 다운로드하고 보관할 폴더에 압축을 푸세요. GitHub의 “Source code”가 아닌 확장 프로그램 패키지를 선택하세요.

  2. 확장 프로그램 관리 열기.

    Chrome 주소창에 chrome://extensions을 입력하세요.

  3. 확장 프로그램 불러오기.

    개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 선택한 다음 manifest.json이 있는 압축 해제 폴더를 지정하세요.
