模型，由你选择。

通过服务地址和 API Key 连接你已有的模型服务。旁白支持以下接口：

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

也支持通过 localhost 访问兼容的本地模型服务。

直接连接，数据去向清楚。

请求直接发送到你配置的服务。旁白无需注册账号，没有中转服务器，也不采集使用分析。设置、密钥、收藏与调用记录保存在你的浏览器中。

开始前，你可能想知道。

旁白需要付费吗？

旁白采用 MIT 许可证，免费且开源。AI 功能需要你自行提供模型访问方式，模型服务商可能按请求计费；旁白不包含模型订阅或 API 额度。

哪些模型可以使用？

选择支持上述四种接口之一的服务商。在“模型连接”中填写服务地址和 API Key，测试连接后选择模型。你可以保存多个连接，为不同处理方式选择不同模型。

可以使用本地模型吗？

可以，前提是本地服务提供兼容的 API。对于 OpenAI 兼容接口，选择 Chat Completions 并填写本机服务地址。例如，Ollama 提供 OpenAI 兼容 API；实际使用取决于服务和模型支持的请求能力。本地 HTTP 地址限于 localhost、127.0.0.1 或 [::1]。

阅读内容会发送到哪里？

翻译及其他 AI 功能会将所需内容直接发送到你选择的模型服务。开启整页翻译后，滚动页面可能继续发送新的段落。配置模型后，每天首次打开收藏页会生成今日随想，也可选择参考收藏；隐藏随想区域即可停止自动生成。服务商自己的数据政策适用于其收到的请求。阅读隐私政策（英文）。

下载已经构建好的扩展，无需安装 Node.js 或构建工具。

  1. 下载扩展。

    点击下方按钮获取扩展 ZIP 安装包。请使用打包好的扩展，不是 GitHub 自动生成的“Source code”源码包。

  2. 解压并保留文件夹。

    将 ZIP 解压到一个固定目录。Chrome 会从这个文件夹加载扩展，请保留它。

  3. 在 Chrome 中加载。

    打开 chrome://extensions，开启开发者模式，点击加载已解压的扩展程序，选择刚刚解压的文件夹。
