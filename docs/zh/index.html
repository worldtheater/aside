模型，由你选择。

通过服务地址和 API Key 连接你已有的模型服务。旁白支持以下接口：

  • OpenAI Responses
  • OpenAI-compatible Chat Completions
  • Anthropic Messages
  • Gemini Interactions

也支持通过 localhost 访问兼容的本地模型服务。

直接连接，数据去向清楚。

请求直接发送到你选择的模型服务，没有旁白中转服务器，也不采集使用分析。收藏与请求记录保存在你的浏览器中。

开始前，你可能想知道。

旁白需要付费吗？

旁白采用 MIT 许可证，免费且开源。AI 功能需要你自行提供模型访问方式，模型服务商可能按请求计费；旁白不包含模型订阅或 API 额度。

哪些模型可以使用？

选择支持上述四种接口之一的服务商。在“模型连接”中填写服务地址和 API Key，测试连接后选择模型。你可以保存多个连接，为不同处理方式选择不同模型。

可以使用本地模型吗？

可以，只要本地服务提供兼容 API，例如 Ollama。选择 OpenAI-compatible Chat Completions，填入 localhost 地址；服务和模型须支持所用请求。 也支持 HTTP 服务地址。建议优先使用 HTTPS；HTTP 不加密 API Key 和请求内容。

阅读内容会发送到哪里？

微软翻译将文字直接发送到微软。AI 功能会将所需内容直接发送到你选择的模型服务。开启整页翻译后，滚动页面可能继续发送新的段落。配置模型后，每天首次打开收藏页会生成今日随想，也可选择参考收藏；隐藏随想区域即可停止自动生成。服务商自己的数据政策适用于其收到的请求。阅读隐私政策（英文）。

手动安装。

选择浏览器，按步骤加载本地扩展。

  1. 下载并解压。

    下载扩展 ZIP，解压到一个固定目录。请选择扩展安装包，不是 GitHub 的“Source code”源码包。

  2. 打开扩展管理页。

    在 Chrome 地址栏输入 chrome://extensions。

  3. 加载扩展。

    开启开发者模式，点击加载已解压的扩展程序，选择解压后包含 manifest.json 的文件夹。

下载 Chrome ZIP 完整安装指南
