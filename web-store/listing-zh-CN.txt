旁白帮助你理解并留下网页中值得记住的内容。在原页面翻译文字、解释概念、提出问题，并收藏有用的结果。

使用你自己的模型服务
AI 功能需要自行配置兼容的模型服务地址，以及该服务要求的 API Key。旁白不包含模型额度或托管 AI 订阅，模型服务可能单独收费，其条款由对应服务商制定。

在阅读中理解
• 翻译选中文字或网页，保留原文对照；滚动时继续处理后续内容。
• 解释难懂的内容、释义古文或提炼要点。
• 通过快问快答询问选中文字或当前页面，也可以清空引文独立提问。
• 创建常用处理方式，自定义要求、输出语言、模型和结果位置，保存前可以试运行。

保存与回顾
• 收藏处理结果，保留原文和来源链接，之后可以搜索、复制和重读。
• 生成今日随想，可选择参考收藏片段。配置模型后，每天首次打开收藏页时可自动生成；也可手动刷新，或隐藏随想区域停止自动生成。
• 查看模型用量、请求输入与输出，管理本地结果缓存。

舒适阅读
• 内置 Dark Reader 暗色引擎，按网站开启、关闭暗色模式或跟随系统。
• 调整结果颜色、字号与行距，选择旁白界面的明暗主题。
• Alt+Q 打开快问快答，Alt+W 在当前窗口最近浏览的两个标签页间切换。可在 Chrome 中修改快捷键；已有快捷键可能发生冲突。

自己的服务，本地保存
模型请求从插件直接发送到你选择的服务地址。API Key、设置、收藏、请求记录和缓存保存在本地浏览器。使用模型功能时，所需文字和指令会发送给该服务。旁白没有开发者中转服务、分析追踪或云同步；服务商如何处理请求，以其隐私政策为准。

支持 OpenAI Responses、兼容 OpenAI 的 Chat Completions、Anthropic Messages 和 Gemini Interactions 协议。远程服务使用 HTTPS，也可配置受支持的本地 HTTP 地址。可用模型与能力取决于服务商。

界面支持英文、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语、葡萄牙语（巴西）、俄语、印尼语、意大利语、土耳其语、泰语和越南语。

页面工具适用于 Chrome 允许扩展运行的普通 HTTP/HTTPS 网页，不支持浏览器内部页面、Chrome Web Store 等受限页面。
